# 앱 구현 방식

(2026-08-17 확정)

- 제품 화면 구현은 이 저장소의 `apps/web`에서 한다. 스펙 번들과 구현이 한 저장소·한 git 히스토리로 묶여, 구현 AI가 같은 컨텍스트에서 스펙을 읽고 스펙 버전과 구현 변경이 함께 추적된다.
- 스택은 Vite + React + TypeScript + Tailwind CSS v4 + lucide-react다. 와이어프레임 수치가 Tailwind 파생 값이라 토큰 복원이 1:1이고, 식별된 아이콘이 lucide이기 때문이다.
- 폰트는 Pretendard를 CDN 가변 폰트로 로드한다(전역 관례 문서 3번).
- **화면 구현은 파이프라인 검증 실험이다.** 구현 중 스펙 번들만으로 답할 수 없었던 것을 화면별 파일럿 문서의 마찰 로그에 기록한다. 스펙·파이프라인의 추가 형식화(예: interpretation의 JSON 승격, 2차 정규화 단계)는 마찰 로그의 증거로만 결정하고, 추측으로 형식화하지 않는다.
