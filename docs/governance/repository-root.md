# VADA 정식 저장소 경계

- 상태: 확정
- 결정일: 2026-07-27
- 프로젝트 ID: `vada`
- 정식 원격 저장소: `https://github.com/vada-hq/vada.git`

## 결정

VADA의 코드·실행 계약·검증·저장소 문서는 하나의 Git 루트에서 관리한다. 로컬 디렉터리의 이름이나 절대 경로가 아니라 `.vada/project.json`의 프로젝트 ID와 Git 원격을 저장소 식별자로 사용한다.

`VADA-wireframe`에서 관리하던 자산은 역할에 따라 다음 위치로 통합한다.

- 실행 계약: `contracts/`
- 와이어프레임 참고 문서: `docs/reference/wireframe/`
- 실행 가능한 화면 프로토타입: `prototypes/wireframe/`

## 이유

수직 슬라이스는 DB·API·화면·테스트·문서를 함께 바꾼다. 하나의 저장소에 있어야 계약과 구현을 같은 변경 집합과 CI에서 검증할 수 있고, 에이전트가 서로 다른 저장소 리비전을 조합하는 오류를 막을 수 있다.

## 운영 규칙

- VADA 작업 세션은 이 Git 루트 또는 그 하위 디렉터리에서 시작한다.
- 기계별 로컬 경로는 저장소 문서에 정본으로 기록하지 않고 사용자 수준 실행기에 둔다.
- 외부에 남은 `VADA-wireframe` 폴더는 통합 검증 전 백업으로만 보존하며 새 정본 변경을 만들지 않는다.
