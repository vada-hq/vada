# 백로그

미착수 항목의 단일 추적처다. 스코프 태그([파이프라인]/[vada])를 붙이고, 착수 시점(트리거)이 있으면 명시한다. 완료하면 행을 삭제한다. 진행 상태는 `HANDOFF.md`, 화면별 발견은 각 파일럿 문서의 마찰 로그가 원본이다.

**마지막으로 훑은 날 2026-08-29.** 이날 121줄 중 13줄이 이미 한 일이었다 — 그중 넷은 본문에 "해결됨"이라고 적혀 있는데도 지워지지 않았다. 낡은 백로그는 남은 일의 크기를 부풀려 **우선순위를 여기서 뽑을 수 없게 만든다.** 지우는 것이 적는 것의 절반이다.
