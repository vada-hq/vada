## 확정 사항 (2026-07-18)

- 행사 하위 탭의 순서·명칭은 v5 도식이 아니라 **핸드오프 문서가 기준**이다.
  v5의 `개요→업무→관련 회의→일정→재정→참여자→문서` 대신
  핸드오프의 `개요→업무→재정→관련 회의→일정→인원 관리→문서`를 유지한다.
- 내 업무(MY-01)는 v5 기준 상태 3분류(해야 할 / 진행 중인 / 완료된 업무)로 재편한다.
- 감사 보고서 기능은 절대 구현하지 않는다.

## 메뉴 대응 신규 화면 (2026-07-19 구현 완료)

- 운영 > 상시 업무 → `OPS-TASK-01`
- 운영 > 캘린더 → `OPS-CAL-01`
- 재정 > 사용 내역 → `FIN-LEDGER-01`
- 기록 > 회의·결정 기록 → **별도 화면을 만들지 않기로 결정 (2026-07-19).** 완료 회의 상세는 `OPS-MEET-07` 완료 회의록이 유일한 원본으로 담당한다. `REC-02`는 회의 기록이 아닌 완료 행사 아카이브 전용 화면이다.
- 조직 관리 > 역할 및 권한 → `ORG-04` (열람 전용 — 2026-07-19 확정된 `VADA_PERMISSION_MATRIX.md` 반영 완료, 미정 항목 없음)
- 행사 > 관련 회의 → `EVT-MEET-01` (행사 연결 회의 열람·기존 회의 상세 진입)
- 행사 > 일정 → `EVT-SCHED-01` (행사 주요 일정 열람)
- 행사 > 문서 → `EVT-DOC-01` (행사 공통 문서 현황 열람)

## 재정 메뉴 매핑 (2026-07-19 확정)

재정 = 학생회 전체 재정을 보는 곳, 행사 > 재정 = 해당 행사 맥락의 재정 처리.

- 예산 현황 → `FIN-00`
- 구매 요청 → `FIN-WORK-01` (목록·검토 진입, 구 "재정 처리함"을 재정의) + `FIN-REQ-01/02` (작성·상세)
- 사용 내역 → `FIN-LEDGER-01`
- 증빙 관리 → `FIN-EVID-01`
- "재정 처리함" 개념은 제거함 — 행사>재정과 처리 속성이 중복된다는 결정에 따름

## 위치 확정 (2026-07-19)

- 내 구매 요청(MY-REQ-01) → `운영 > 행사 > 재정 > 내 구매 요청`. 행사 스코프의 개인 요청 화면으로 재정의, EVT-FIN-01의 `내 구매 요청` 버튼으로 진입. 내 업무 하위에서는 제거 (핸드오프의 이전 경로 규칙을 대체)
- 학생 명단(ORG-07A/B) → `조직 관리 > 학생 명단` 하위 메뉴로 확정. 조직 관리 진입 시 허브(ORG-00)에서 부서&구성원 / 학생 명단 / 역할 및 권한 중 선택
- 온보딩·학생회 생성·외부 참여(모바일)는 워크스페이스 메뉴 밖 영역이므로 트리에 없는 것이 정상
