# VADA 권한 매트릭스 (확정)

> ⚠️ 와이어프레임 이력 스냅샷입니다. 실행 정본은 `contracts/permissions.json`, 승인·영향 관계는 Notion 계약 리비전 DB를 따릅니다. 문서 경계는 `docs/README.md`를 참고하세요.

2026-07-19 작성·사용자 검토 완료. 구현된 78개 화면에 실제로 존재하는 기능(버튼·액션) 기준이며, **이 표가 역할별 버튼 노출과 ORG-04 화면의 단일 기준이다.**

- 검토에서 수정된 항목 2건: 회의 생성(전 구성원 → 회장단·부서장), 학생 명단 열람(회장단·부서장 → 전 구성원)
- 표의 모든 항목은 현재 범위에서 확정된 권한 규칙이다.

## 역할 축

- 기본 직급: 회장단 / 부서장 / 부원 — "전 구성원" = 셋 전부
- 부서 조건: 재정부 (직급 무관, 재정부 소속)
- 맥락 역할(사안별 부여): 회의 생성자, 회의 진행 권한자, 회의 참가자(초대됨), 행사 운영 조직(행사별, 기본 조직과 별개)
- 외부: 일반 학생 (가입·로그인 없이 모바일 웹)
