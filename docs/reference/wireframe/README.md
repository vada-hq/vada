# 와이어프레임 참고 문서

2026-07-27 이전 `VADA-wireframe/docs`에서 관리하던 화면 정의와 QA 산출물을 보존한다.

- `VADA_HANDOFF.md`: 와이어프레임 화면과 탐색 구조
- `VADA_MENU_STRUCTURE.md`: 메뉴 구조 참고
- `VADA_PERMISSION_MATRIX.md`: 과거 권한표
- `VADA_EVENT_ARCHIVE_SPEC.md`: 행사 아카이브 화면 명세
- `VADA_SCREEN_QA.md`: 와이어프레임 화면 QA 매트릭스

이 디렉터리는 정책 정본이 아니다. 권한·데이터·상태·API 판단은 루트 `contracts/`의 활성 리비전과 연결된 Notion 결정 기록을 따른다.
