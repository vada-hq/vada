## 가장 중요한 사용자 원칙

- **기획은 사용자가 확정·채택한다고 말한 뒤에만 문서에 저장한다.** 미확정 제안을 문서에 선저장하지 않는다. 이번 인계 문서는 사용자가 명시적으로 요청한 작업 상태 기록이며, 아래 시안 내용의 채택을 의미하지 않는다.
- 모든 Chrome 작업 탭은 **`codex` 그룹**에서 연다. 기존 그룹을 우선 사용한다.
- 시안은 **기존 VADA 와이어프레임의 디자인을 유지하여 앱 안에 추가**한다. 별도 디자인의 외부 HTML 미리보기를 주 작업 화면으로 사용하지 않는다.
- 홈의 핵심 정보가 현재 데스크톱 창에서 **드래그·스크롤 없이 한 화면에 들어가야 한다.** 정보를 잘라 숨기는 방식으로 맞추지 않는다.
- 최신 글씨 지시: **기존 VADA와 동일한 글꼴과 글씨 크기**. 앞선 ‘크게’, ‘조금 줄여’ 요청보다 이 지시를 우선한다.
- 기본 대화는 한국어. 변경 요청이 없는 검토는 읽기·보고만 수행한다.

## 역할·권한 이해의 기준

회장단 > 부서장 > 부원 순으로 모든 권한이 상속되는 구조가 아니다.

| 축 | 의미 |
|---|---|
| 기본 직급 | 회장단·부서장·부원 |
| 소속 부서 | 재정부 여부. 직급과 별개로 재정 처리 권한 판단 |
| 행사별 역할 | 해당 행사 운영 조직 관리자·구성원 |
| 회의별 역할 | 생성자·진행 권한자·참가자 |
| 관계·상태 | 본인 요청 여부, 방 참여 여부, 검토·주문·행사 상태 등 |

- 회장단: 조직 관리와 행사 최종 완료. 재정부 소속이 아니면 재정 승인·발주·예산 조정 권한 없음.
- 구매 요청 작성: 재정부 또는 부서장. 회장단 직급 자체는 조건에 포함되지 않는다.
- 부서장: 행사·회의 생성, 자기 부서 초대, 구매 요청과 본인 요청 후속 처리. 모든 부서 업무·다른 사람의 요청을 관리하는 권한으로 확대 해석하지 않는다.
- 부원도 해당 행사 관리자나 회의 진행 권한자가 될 수 있다.
- 행사 종료는 회장단 또는 행사 관리자, 최종 완료는 회장단만 가능.
- 회의 수정·취소·진행 권한 부여는 생성자, 시작·종료·정리는 진행 권한자.
- 비공개 회의와 메시지는 회장단에게도 일괄 공개되지 않는다. 홈 집계에도 접근 범위를 적용해야 한다.
- 재정부는 직급과 무관한 소속 조건. 구매 검토·발주·수령/이행 확인·실지출 확정 등을 담당한다.
- 홈에 생략하는 것과 열람 권한이 없는 것은 다르다. 열람 가능·처리 가능·홈 우선 노출을 따로 판단한다.
