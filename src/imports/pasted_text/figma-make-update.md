현재 최신 Figma Make 수정본을 기준으로 작업해줘.

기존 화면의 정보구조와 디자인 방향은 대부분 적절하므로, 관련 없는 화면을 재설계하거나 동일 화면을 중복 생성하지 말고 다음의 데이터 연결 및 인터랙션 문제를 우선 수정해줘.

이번 작업의 핵심 목표는 다음 세 가지다.

1. 행사 기본정보를 모든 관련 화면이 함께 사용하는 단일 원본으로 만든다.
2. 참여 설문 링크 활성화 조건을 실제 입력값으로 계산한다.
3. 화면정의서에 적힌 이동·저장·자동 반영 동작을 실제 프로토타입에서도 작동시킨다.

## 1. 공통 입력 컴포넌트부터 수정

현재 일부 공통 입력 컴포넌트가 호출부에서 전달한 초기값과 변경 이벤트를 실제 입력칸에 전달하지 않아, 저장된 값이 있는데도 입력란이 비어 있다.

공통 Input, Textarea, Checkbox 컴포넌트가 다음 속성을 빠짐없이 실제 HTML 요소에 전달하도록 먼저 수정한다.

- value
- defaultValue
- checked
- onChange
- onBlur
- disabled
- type
- placeholder
- min
- max
- aria 관련 속성

모든 편집 화면은 제어되는 입력값을 사용하고, 화면에 표시된 값과 내부 상태가 달라지지 않게 한다.

## 2. 하나의 행사 기본정보 상태 사용

앱의 최상위 영역에서 하나의 공통 행사 기본정보 상태를 관리하고 다음 화면이 모두 동일한 데이터를 사용하게 한다.

- EVT-02 행사 개요
- EVT-02B 행사 기본정보 입력·수정
- EVT-05 참여 설문 생성·관리
- EXT-02A 외부 참여 설문
- 일정 및 공지에 행사 정보를 표시하는 영역

화면마다 행사명·일시·장소·참가비 등을 별도의 고정 문구로 작성하지 않는다.

공통 행사 기본정보에는 다음 값이 포함되어야 한다.

### 행사 정보

- 행사명
- 행사 소개
- 행사 목적·주요 내용

### 일시

- 시작 일시
- 종료 일시
- 종료 시간 미정 여부

### 장소

- 장소 확정 여부
- 장소명
- 주소
- 상세 위치·집합 장소

### 참여 정보

- 참가 대상
- 참가비 유형
- 참가비 상세 정보
- 행사 정원 유형
- 정원 인원

### 담당 및 안내

- 담당 부서
- 담당자
- 문의 방법·연락처
- 참가자 유의사항

별도로 참여 설문 설정 상태를 관리한다.

- 신청 시작 일시
- 신청 마감 일시
- 신청 방식
- 대기 신청 운영 여부
- 학생회비 납부 여부 대조 여부
- 신청 완료 안내 문구
- 설문 문항
- 개인정보 동의 문항
- 설문 상태
- 현재 응답 수

행사 기본정보와 설문 설정을 서로 다른 고정 데이터로 만들지 않는다.

## 3. EVT-02B 기존 정보 수정 상태 정상화

기존 행사 정보를 수정하는 상태에서는 현재 저장된 값을 모든 입력란에 미리 채운다.

현재 행사 개요와 참여 설문에 표시된 다음 값들이 편집 패널에서는 빈칸으로 나타나는 문제가 있으므로 수정한다.

- 행사명
- 장소
- 참가 대상
- 참가비
- 정원
- 담당 부서
- 담당자
- 문의처
- 유의사항

신규 행사인 경우에는 행사 생성 시 입력한 행사명만 채우고 나머지는 비어 있는 상태로 보여준다. 조회 화면에서는 빈 값을 `미정`으로 표시한다.

기존 행사 수정 상태와 신규 행사 최초 입력 상태를 혼합하지 않는다.

## 4. 편집 임시값과 저장값 구분

EVT-02B를 열면 현재 저장값을 복사한 편집 임시값을 만든다.

- 사용자가 입력하는 동안에는 편집 임시값만 변경한다.
- `취소`를 누르면 변경 내용을 버리고 기존 저장값으로 돌아간다.
- `저장` 또는 `저장 완료`를 누르면 편집 임시값을 공통 행사 기본정보에 반영한다.
- 저장 이후 행사 개요·참여 설문·외부 설문에 같은 값이 즉시 표시되어야 한다.

## 5. 참가비 유형 확장

현재 `무료 / 유료 / 미정` 구조만으로는 VADA의 실제 사례인 `학생회비 납부자 무료 / 미납자 5,000원`을 표현할 수 없다.

참가비 유형을 다음과 같이 수정한다.

- 무료
- 정액 유료
- 학생회비 납부 여부에 따라 다름
- 미정

### 무료

추가 금액 입력란을 보여주지 않는다.

### 정액 유료

다음 입력란을 노출한다.

- 참가비 금액
- 결제 안내

### 학생회비 납부 여부에 따라 다름

다음 입력란을 노출한다.

- 학생회비 납부자 금액
- 학생회비 미납자 금액
- 결제 안내

납부자 금액은 0원으로 설정할 수 있다.

참여 설문과 외부 설문에서는 이를 단순히 `참가비 5,000원`으로 축약하지 말고 다음처럼 정확하게 표시한다.

`학생회비 납부자 무료 / 미납자 5,000원`

이 유형을 사용하면서 참여 설문을 활성화하려면 다음 조건도 확인한다.

- 학생회비 납부 여부 대조 기능 활성화
- 이름 문항 존재
- 학번 문항 존재
- 이름·학번 문항 필수 응답 설정

명단과 일치하지 않는 신청자는 미납으로 자동 판단하지 말고 `확인 필요`로 분류한다.

## 6. 행사 정원 조건 수정

행사 정원 유형은 다음과 같이 유지한다.

- 제한 없음
- 인원 제한
- 미정

`인원 제한`을 선택한 경우에만 정원 인원 입력란을 노출한다.

참여 설문 활성화 조건에도 정원 정보를 포함한다.

- 제한 없음: 조건 충족
- 인원 제한 + 유효한 정원 인원: 조건 충족
- 인원 제한 + 정원 미입력: 조건 미충족
- 미정: 조건 미충족

정원이 제한 없음인 경우에는 대기 신청 설정을 숨기거나 비활성화한다.

## 7. EVT-02 행사 개요의 정보 소유권 수정

`행사 기본 정보` 카드에서는 행사 자체의 공통 정보만 보여준다.

- 행사명
- 일시
- 장소
- 참가 대상
- 참가비
- 행사 정원
- 담당자·문의처

현재 행사 기본정보 카드에 포함된 `신청 기간`은 제거한다.

신청 기간과 신청 방식은 별도의 `모집 설정 요약` 영역으로 분리한다.

모집 설정 요약에는 다음 내용을 보여준다.

- 설문 상태
- 신청 시작·마감 일시
- 신청 방식
- 대기 신청 여부
- 현재 신청자 수
- `참여 설문에서 수정` 버튼

## 8. 행사 상태와 기능 상태 분리

행사의 생애주기 상태와 설문·QR의 기능 상태를 하나의 상태처럼 사용하지 않는다.

### 행사 상태

- 기획 중
- 진행 중
- 후속 정리 중
- 완료

### 참여 설문 상태

- 초안
- 활성
- 종료
- 교체됨

### QR 참석 확인 상태

- 미설정
- 설정 완료
- 활성
- 종료

행사가 `기획 중`이어도 모집 설문이 활성화되어 신청자가 존재할 수 있다.

다만 행사 시작 전 QR 참석 확인은 `활성`으로 표시하지 않는다. QR이 미리 설정되어 있다면 다음처럼 표시한다.

`설정 완료 · 행사 시작 시 활성화`

행사 시작 또는 설정한 참석 확인 시간이 되었을 때만 `활성`으로 전환한다.

## 9. 링크 활성화 조건을 실제 데이터로 계산

활성화 조건의 완료 여부를 고정된 true/false 값으로 작성하지 않는다.

공통 행사 기본정보, 설문 설정, 설문 문항의 현재 값을 기준으로 매번 다시 계산한다.

### 행사 기본정보 조건

- 행사명 입력
- 시작 일시 입력
- 종료 일시 입력 또는 `종료 시간 미정` 선택
- 장소 확정 및 장소명 입력
- 참가 대상 입력
- 참가비 유형 확정
- 정액 유료라면 금액과 결제 안내 입력
- 학생회비 조건부 참가비라면 납부자·미납자 금액과 결제 안내 입력
- 행사 정원 유형 확정
- 인원 제한이라면 유효한 정원 입력

### 참여 설문 설정 조건

- 신청 시작 일시
- 신청 마감 일시
- 신청 시작 일시보다 마감 일시가 늦음
- 신청 방식 선택
- 이름 필수 문항 존재
- 학번 필수 문항 존재
- 개인정보를 수집하므로 개인정보 수집·이용 동의 문항 존재
- 학생회비 대조를 사용하면 필요한 식별 문항 존재

행사 소개·목적·유의사항·문의처 등 선택 정보는 링크 활성화를 막지 않는다.

## 10. 활성화 조건의 실시간 갱신

사용자가 신청 마감 일시나 누락된 값을 입력하면 즉시 다음 항목을 다시 계산한다.

- 미충족 항목 수
- 각 조건의 완료 상태
- 링크 활성화 버튼 상태
- 누락 안내 문구

예를 들어 신청 마감 일시를 입력하면 `미충족 1개`가 즉시 `미충족 0개`로 변경되어야 한다.

필수값을 다시 지우면 미충족 수가 다시 증가해야 한다.

## 11. 링크 활성화 버튼의 실제 비활성화

활성화 조건이 남아 있을 때는 버튼의 투명도만 낮추지 말고 실제 disabled 상태를 적용한다.

- 클릭되지 않아야 한다.
- 키보드 포커스로 실행되지 않아야 한다.
- 비활성화 이유를 확인할 수 있어야 한다.
- 미충족 항목 수를 버튼 주변에 표시한다.

모든 조건이 충족되면 실제로 활성화 버튼을 사용할 수 있게 한다.

버튼을 누르면 다음 상태로 변경한다.

- 설문 상태: `초안 → 활성`
- 외부 설문 링크 생성
- QR 생성
- 참여 설문 관리 화면에 활성 상태 표시

## 12. 누락 항목 바로가기 버튼 연결

다음 버튼을 실제로 연결한다.

### 행사 기본정보에서 수정

EVT-02B로 이동하고 해당 누락 입력란으로 스크롤한 뒤 포커스를 준다.

예시:

- 장소 누락 → 장소 입력란
- 참가비 누락 → 참가비 영역
- 정원 누락 → 정원 인원 입력란

수정 후 참여 설문으로 돌아왔을 때 작성하던 설문 문항과 설정을 유지한다.

### 모집 설정에서 입력

같은 EVT-05 화면의 모집 설정 영역으로 스크롤하고 해당 입력란에 포커스를 준다.

### 필수 문항 추가

필요한 문항을 추가하거나 해당 문항 설정으로 이동한다.

버튼을 시각적으로만 만들고 onClick을 비워두지 않는다.

## 13. 개인정보 동의 및 식별 문항 조건

이름과 학번은 참가자 식별에 필요한 기본 문항으로 유지한다.

학생회비 대조를 사용하는 동안에는 이름·학번 문항을 삭제하거나 선택 응답으로 변경할 수 없게 한다.

개인정보 동의 문항을 삭제하면 링크 활성화 조건이 즉시 미충족으로 바뀌어야 한다.

화면에 개인정보 동의 문항이 없는데 조건만 완료로 표시되는 일이 없어야 한다.

## 14. 저장 확인 모달을 실제 변경값으로 생성

현재 저장 버튼을 누르면 사용자가 변경하지 않았는데도 다음과 같은 고정 변경 내역이 나타나는 문제를 수정한다.

`2026. 08. 20 → 2026. 08. 21`

저장 모달은 기존 저장값과 편집 임시값을 비교하여 실제로 변경된 항목만 표시한다.

- 변경 사항이 없으면 변경 확인 모달을 띄우지 않는다.
- 설문이 아직 초안이면 바로 저장한다.
- 설문이 활성 상태이고 공개 정보가 변경된 경우에만 확인 모달을 표시한다.
- 일시·장소·참가비·참가 대상 등의 실제 이전 값과 새 값을 표시한다.
- 자동 반영되는 화면을 함께 표시한다.

행사 정보 변경은 차단하지 않는다.

활성 설문의 링크와 기존 응답은 유지하고, 필요한 경우 `변경 공지 만들기`를 제안한다.

활성화에 필요한 정보를 다시 `미정`으로 변경하더라도 링크를 자동으로 비활성화하지 않는다. 대신 운영진 화면에 `공개 정보 보완 필요` 경고를 표시하고 변경 공지를 제안한다.

## 15. 외부 참여 설문의 자동 반영

EXT-02A 외부 참여 설문은 공통 행사 기본정보와 설문 설정을 직접 사용한다.

다음 값을 고정 문구로 작성하지 않는다.

- 행사명
- 행사 일시
- 장소
- 참가 대상
- 참가비
- 행사 정원
- 모집 마감일

현재처럼 설문 설정에는 마감일이 없는데 외부 화면에는 `마감 07.18`이 표시되어서는 안 된다.

참가비도 조건부 참가비를 단순 `5,000원`으로 표시하지 않는다.

공통 정보가 수정되면 외부 화면 미리보기에도 즉시 같은 값이 나타나야 한다.

## 16. 기존 설문 교체 흐름 보완

활성 설문에 응답이 존재하는 상태에서 문항이나 응답 구조를 변경하려면 기존 EVT-05B 교체 흐름을 사용한다.

- 기존 설문 상태를 `교체됨`으로 변경
- 기존 응답은 기록으로 보존
- 기존 응답은 새 설문의 현재 신청자 집계에서 제외
- 기존 응답자는 재응답 필요 상태로 표시
- 새 설문 초안 생성
- 새 설문이 활성화되면 새로운 링크와 QR 사용

단순 행사 일시·장소·참가비 변경은 설문 교체 사유로 보지 않는다.

## 17. 반응형 레이아웃 수정

현재 좁은 미리보기에서 행사명·참가 대상·문의 정보가 한 글자씩 줄바꿈되고 오른쪽 내용이 잘리는 문제가 있다.

다음과 같이 수정한다.

- 한국어 문구에 한 글자 단위 줄바꿈이 발생하지 않게 한다.
- 카드와 그리드 자식에 적절한 최소 너비와 `min-width: 0`을 적용한다.
- 긴 값은 단어 단위로 자연스럽게 줄바꿈한다.
- 좁은 화면에서는 행사 기본정보 요약을 한 열로 배치한다.
- 질문 설정 패널은 좁은 화면에서 오른쪽 고정 열이 아니라 drawer 또는 하단 영역으로 전환한다.
- 화면 너비가 부족하면 3열 구조를 1열 또는 2열로 재배치한다.
- 가로로 잘린 내용을 방치하지 않는다.

## 18. 화면정의서 동기화

화면정의서에 적힌 내용과 실제 동작이 일치하도록 수정한다.

특히 다음 항목을 실제 구현과 대조한다.

- 기본정보 단일 원본
- 기존 값 미리 채우기
- 신청 기간의 소유 위치
- 조건부 참가비
- 정원 활성화 조건
- 누락 항목 바로가기
- 링크 활성화 버튼의 실제 disabled 상태
- 자동 반영
- 실제 변경값 기반 저장 모달
- 외부 설문 자동 반영
- 반응형 레이아웃
- 행사 상태와 설문·QR 상태의 분리

실제로 구현되지 않은 동작을 화면정의서에 완료된 기능처럼 작성하지 않는다.

## 19. 최종 검수 시나리오

다음 시나리오를 모두 실제로 실행하여 확인해줘.

1. EVT-02B에서 행사명을 변경하고 저장하면 EVT-02, EVT-05, EXT-02A에 같은 행사명이 표시된다.
2. 기존 행사 편집 화면을 열면 장소·대상·참가비·정원·담당자 등 기존 값이 채워져 있다.
3. 신청 마감 일시를 입력하면 미충족 항목 수가 즉시 감소한다.
4. 신청 마감 일시를 다시 지우면 미충족 항목 수가 증가한다.
5. 인원 제한을 선택하고 정원을 비우면 정원 조건이 미충족으로 표시된다.
6. 정원 200명을 입력하면 해당 조건이 완료된다.
7. 정액 유료를 선택하고 금액이나 결제 안내를 비우면 미충족으로 표시된다.
8. 학생회비 조건부 참가비를 선택하면 납부자·미납자 금액과 대조 기능 조건이 표시된다.
9. `행사 기본정보에서 수정` 버튼이 실제 EVT-02B로 이동한다.
10. `모집 설정에서 입력` 버튼이 실제 입력란으로 이동한다.
11. 조건이 남아 있으면 링크 활성화 버튼이 실제로 클릭되지 않는다.
12. 조건이 모두 충족되면 링크를 활성화할 수 있다.
13. 변경 사항 없이 저장할 때 고정된 변경 확인 모달이 나타나지 않는다.
14. 실제 변경한 항목만 저장 확인 모달에 표시된다.
15. 외부 설문의 마감일·참가비·행사명이 내부 정보와 일치한다.
16. 행사 시작 전 QR은 `활성`이 아니라 `설정 완료`로 표시된다.
17. 좁은 미리보기에서도 텍스트가 한 글자씩 줄바꿈되거나 잘리지 않는다.

위 검수 시나리오가 통과하기 전에는 화면정의서 문구만 수정하여 완료 처리하지 말고, 실제 상태·입력·버튼 동작을 함께 수정해줘.

이번 수정 범위에서는 재정 기능이나 행사 취소 상태를 새로 추가하지 말고, 기존에 합의한 행사 생애주기와 후속 정리 흐름도 변경하지 말아줘.
