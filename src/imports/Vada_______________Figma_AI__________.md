# Vada Figma AI First Draft 프롬프트

## 사용 방법

1. Figma AI의 First Draft 입력창을 엽니다.
2. 아래 `통합 프롬프트` 전체를 복사해 입력합니다.
3. 한 번에 일부 화면만 만들어지면, 문서 하단의 `화면군별 추가 프롬프트`를 순서대로 입력해 누락 화면을 추가합니다.
4. 결과는 최종 UI가 아니라 팀이 구조와 흐름을 검토하기 위한 1차 저충실도 와이어프레임으로 사용합니다.

---

# 통합 프롬프트

아래 내용 전체를 복사해 Figma AI First Draft에 입력하세요.

```text
대학생 학생회 운영 서비스 "Vada"의 low-fidelity first draft wireframe을 만들어줘.

[프로젝트 목표]
Vada는 학생회 운영자가 학생회 조직을 구성하고, 행사별 운영 조직을 만들고, 일반 학생의 행사 신청·학생회비 상태·참석 여부를 관리하는 내부용 웹 서비스다.
일반 학생은 Vada 회원가입이나 앱 설치를 하지 않고, 행사 참여 설문과 QR 참석 확인 때만 외부 모바일 웹을 사용한다.

[이번 제작 범위]
포함:
- 온보딩과 본인 소속 입력
- 새 학생회 생성과 초대 참여
- 기본 학생회 조직 설정과 구성원 관리
- 행사 운영 조직 설정
- 행사 참가자 명단
- 참여 희망 조사 생성
- 일반 학생용 외부 참여 설문
- QR 참석 확인
- 대표 범위에 따른 학생 명단과 학생회비 상태 관리

제외:
- 구매 요청
- 영수증과 증빙
- 정산
- 감사보고서
- 기타 재정 워크스페이스 전체
참가자 표의 입금 상태와 학생 명단의 학생회비 상태는 표시하지만, 별도의 재정 화면은 절대 만들지 마.

[결과물 형식]

- 모든 화면을 하나의 캔버스에 화면 ID 순서대로 정렬해줘.
- 각 화면 위에 화면 ID와 화면명을 section title로 표시해줘.
- Auto Layout을 사용하고 이후 직접 수정하기 쉬운 구조로 만들어줘.
- 반복되는 요소는 component 또는 variant로 만들어줘.
- 최종 비주얼 디자인이 아닌 정보 구조 검토용 low-fidelity wireframe으로 만들어줘.
- 흰색, 밝은 회색, 진한 회색을 기본으로 사용하고 선택·활성 상태에만 파란색 한 가지를 사용해줘.
- 그라데이션, 사진, 일러스트, 장식적인 배경, 과한 그림자, 완성형 브랜딩은 사용하지 마.
- 모든 화면의 UI 문구는 자연스러운 한국어로 작성해줘.
- 실제 학생회 서비스처럼 현실적인 예시 데이터를 넣어줘.

[내부 화면 공통 레이아웃]
- 왼쪽 고정 사이드바 약 240px
- 상단 헤더 약 64px
- 넓은 메인 콘텐츠 영역
- 사이드바 메뉴: 홈, 내 업무, 운영, 기록, 조직 관리
- 현재 화면에 따라 관련 메뉴를 활성 상태로 표시
- 재정 메뉴는 이번 시안에서 표시하지 마.
- 행사 워크스페이스 내부 탭: 개요, 업무, 관련 회의, 일정, 인원 관리, 문서
- 상단에는 breadcrumb, 화면 제목, 필요한 주요 행동 버튼을 배치

[공통 컴포넌트]
다음 요소를 일관된 컴포넌트로 만들어줘.
- primary button, secondary button, text button, destructive button
- 입력창, 검색창, select, date picker 형태
- 상태 chip
- 구성원 카드
- 부서·팀 카드
- 표와 표 행
- 작은 정보 popover
- 오른쪽 side panel
- 중앙 modal
- 확인 dialog
- toast
- 빈 상태

[구성원 카드 공통 규칙]

- 기본 조직, 미배정 구성원, 행사 운영 조직, 추가 가능한 구성원 영역에서 같은 카드 크기와 정보 순서를 사용
- 부서장·팀장은 카드 상단의 별도 영역에서 일반 구성원과 구분
- drag handle 또는 드래그 가능한 시각적 힌트를 제공

[조직도 공통 규칙]
- 최상단에 회장단 또는 행사 책임자
- 하단에 부서·팀 카드를 가로로 배치
- 최상단과 부서·팀 사이에 연결선 표시
- 부서·팀 카드는 큰 카드
- 내부 구성원은 세로형 작은 카드
- 부서 설명 필드는 만들지 마

[반드시 제작할 desktop 화면]

- 학교 → 단과대학 → 학부·학과의 순차 선택이 보이게 구성
```
