| ID | 날짜 | 결정 | 근거(사용자 발언) |
|---|---|---|---|
| M-01 | 2026-10-12 | **`우리 학생회`는 기존 `상시 업무`의 새 이름**이다. 행사가 아닌 학생회의 상시 업무 공간 | "우리 학생회는 기존의 상시 업무랑 같은 개념인데 이름만 바꾼 거야" |

| M-08 | 2026-10-12 | 공간(우리 학생회·행사) 안 `메시지` 탭 옆에 그 방의 안 읽은 수 배지. 사이드바 공간 목록에는 배지 없음 | "메세지 탭 옆에는 안 읽은 배지를 두면 괜찮겠다" |

v6.2 사이드바: 홈(배지) · 내 업무 · 캘린더 · 재정 · 기록 · 조직 관리 / 공간: 우리 학생회(메시지·업무·회의·일정·재정) · 활성 행사(메시지·개요·업무·회의·일정·문서·재정·인원 관리). 우리 학생회와 행사 모두 누르면 메시지가 첫 화면(2026-10-13 사용자 요청).

변경(2026-10-14): 공간 메시지는 `공지방`(공간 전체)과 `부서방`(공간 안의 내 부서)으로 나뉘고, 구매 후보는 부서방의 쇼핑 링크만 자동으로 모은다. 공지방·사이드챗 링크는 `부서방으로 옮기기`. 자세한 결정은 [구매 후보 기획](../chat-purchase/design.md) P-11~P-19. 앞선 `담을 공간 선택`·`우리 학생회 링크 → 상시 지출 자동 수집`안은 이 결정으로 대체됐다.

## 2. 메시지 연결 방식 — 채택

| ID | 날짜 | 결정 | 근거 |
|---|---|---|---|
| M-09 | 2026-10-13 | **대화방은 사용자가 만들지 않고 미리 연결되어 있다.** 부서와 부서, 사람과 사람의 연결이 처음부터 있다(같은 상대 조합에는 언제나 방 하나) | "대화방은 모두 미리 만들어두는거야 … 연결을 미리 시켜놓는거지" |
| M-10 | 2026-10-13 | **조직도 입구는 두지 않고 사이드챗을 1:1의 주력으로 한다.** 메시지 기본 화면은 내 부서 방(회장단은 회장단 방), `/이름`으로 옆에 1:1 사이드챗을 연다 | "기본적으로 우리 부서방이고 '/이름'을 하면 옆에 사이드챗" → "조직도는 일단 빼고 … 사이드챗을 주력으로" |

## 3. 사이드챗 — 채택(추천안 그대로, 2026-10-13 "추천대로 해주고")

| ID | 결정 |
|---|---|
| M-11 | **진입**: 입력창 `/` 자동완성(사람: 이름·부서·역할·담당 업무 / 부서: `부서 전체에 묻기` / 직책: `/홍보부장`), 대화방에서 보낸 사람 이름 누르기, 다른 화면의 사람 이름 누르기, 1:1 메시지 알림 누르기 |
| M-12 | **A. 범위**: 사이드챗은 메시지 화면뿐 아니라 **모든 화면 오른쪽에서** 열린다 · **B. 동시에 하나만** 열고 사이드챗 위 `최근 1:1` 칩 3개로 전환 |
| M-13 | **C. `/이름` 뒤에 친 글은 사이드챗 입력창으로 옮겨 두고 자동으로 보내지 않는다** · **D. `/부서`를 고르면 사이드챗에 `내 부서 ↔ 그 부서` 방**이 열린다(다른 부서 내부 방은 보지 않음) |
| M-14 | **E. 1:1은 어디서 열어도 사이드챗으로 연다**(홈 메시지함·전체 목록의 1:1 묶음 포함) · **F. 사이드챗은 1:1과 부서 간만**, 3명 이상은 공간 방에서 |
| M-15 | **오발송 방지**: 열리면 커서가 사이드챗으로 이동 · 보내기 버튼은 `정하늘님에게 보내기`처럼 받는 사람 이름 · 색·제목을 메인 방과 다르게 · 닫아도 쓰다 만 글 유지(Esc로 닫기) · 입력 안내 `@ 부르기 · / 1:1 대화`로 `@`(방 안에서 부르기)와 구분 |

함께 적용하는 규칙(앞선 제안을 사이드챗 맥락에서 그대로 사용):
- 이름을 모를 때: `/홍` → 홍보부 사람들이 역할·담당 업무와 함께, 맨 위 `부서 전체에 묻기`. 부서에 묻고 한동안 답이 없으면 부서장에게 알림(제안).
- 1:1에서 쿠팡 링크가 오가면 `담을 공간 선택`(공간 방이 아니므로).
- 1:1과 부서 간 방은 참여자만 본다. 회장단에게도 공개하지 않는다. 행사 아카이브에 들어가지 않는다.
- 모바일: 사이드챗은 전체 화면으로 열리고 뒤로 가면 원래 방.

## 5. 와이어프레임

- `MSG-04 대화 — 사이드챗 시안`(2026-10-13): 내 부서 방 + `/` 자동완성 + 사이드챗 + 최근 1:1 칩 + 부서 간 방 + 오발송 방지 장치. 예시 데이터만 쓰며 기존 메시지 방 데이터를 바꾸지 않는다. - 사이드챗 모든 화면 적용(2026-10-13): 공통 화면 틀 오른쪽 패널로 옮기고 상태(열린 대화·쓰던 글·최근 1:1·안 읽음)를 앱 전체가 공유한다. 이름 누르기 적용: 업무 칸반·업무 상세, 회의 후속 업무, 구매 요청 상세·재정 검토 요청자, 공간 메시지·대화 화면 보낸 사람. `/` 자동완성: `MSG-04`·공간 메시지(`US-MSG-01`·`EVT-MSG-01`)·`MSG-03`. 홈 메시지함에 1:1 안 읽음 칩(사이드챗으로 열림, M-14 E), 사이드바 `홈` 배지에 1:1 안 읽음 합산.
