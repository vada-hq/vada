## 1. 목록의 범위와 읽는 방법

현재 93개 와이어프레임의 화면정의서, 주요 데이터 모델, 메뉴·권한·MVP 기준을 대조했다. **홈에 이미 보이는 정보만이 아니라 VADA 각 영역에서 가져오거나 계산할 수 있는 정보**를 열거한다. 입력 폼의 모든 세부 칸은 관련 정보 묶음에 포함하고, 다이얼로그·역할별 변형 화면은 같은 정보를 중복 세지 않는다. 제품 범위가 늘면 이 목록도 갱신한다.

현재 앱은 백엔드 없는 로컬 와이어프레임이다. 아래 ‘원본’은 로컬 데이터 또는 화면 상태가 있다는 뜻이며, 운영 데이터 수집·영속 저장·실시간 동기화·홈 연동이 완료되었다는 뜻이 아니다.

### 제공 준비 상태

- **원본**: 현재 모델·로컬 상태에 값이 있다. 선택 입력이나 비어 있는 값은 ‘미입력’으로 구분한다.
- **계산**: 원본에서 집계·필터·비교할 수 있다. 집계 범위·시점·기준과 홈 연결 구현이 필요하다.
- **예시**: 화면·고정 샘플은 있지만 행사별 실제 입력이나 원본 연결이 불완전하다. 수집·연결 전에는 사실처럼 제공하지 않는다.
- **보류**: 와이어프레임 자산 또는 기획은 있으나 현재 MVP 대상이 아니다.
- **추가**: 필요한 데이터나 판정 규칙이 없어 별도 기획·수집이 필요하다.

상태가 둘 이상이면 각각 적용 범위를 적는다. 새 지표는 ‘계산 가능’만으로 자동 채택하지 않는다.

### 회장단 홈 제안 등급

- **우선**: 조직 전체 판단에 직접 필요한 정보. 요약·대상 중심 노출 후보.
- **조건부**: 특정 시기·문제·회장단 자신의 역할과 관계가 있을 때 노출.
- **상세**: 제공은 가능하나 홈에서는 링크로만 연결하고 원래 화면에서 열람.
- **제외**: 현재 홈 후보에서 제외. 기능 삭제나 기존 열람 권한 철회를 뜻하지 않는다.

회장단은 재정부·회의 진행 권한자·모든 비공개 회의 참가자와 동일하지 않다. **노출 추천은 권한 부여가 아니다.** 행사 참가자 상세·회의·메시지·재정 내부 처리 정보는 기존 권한을 별도로 확인한다.

## 3. 회장단 채택 상태와 이전 제안

**2026-09-30 회장단 홈 정보 채택(D-06).** 최신 확정 내용은 [역할별 문서 §3](role-recommendations.md#3-회장단-홈-정보--채택-2026-09-30-d-06)을 따른다.

- 우선 정보: 전체 행사 현황, 운영상 확인 필요 상황, 후속 정리 중 행사, 가까운 주요 일정, 전체 재정 요약.
- 조건부 정보: 미배정 구성원, 본인의 회의·아카이브 처리 항목.

### 특정 상황에서 추가할 정보

- **모집 중**: 정원 대비 신청 현황·마감·확인 필요 집계(F01~04). 모집 속도·목표 대비 저조 판정은 데이터와 기준 확보 후.
- **행사 직전**: 미확정 장소·책임자/운영 조직 공백·필요일이 임박한 미완료 구매(B04/07, G04/09).
- **행사 당일·직후**: 참석 현황과 검증된 운영 결과(F05, I05).
- **조직 구성·임기 교체**: 미배정 구성원·부서 책임자·인수인계 준비(A03, I07).
- **재정 마감**: 금액 미확정 등 예외의 열람 가능한 요약(G11). 재정부의 처리 권한을 회장단에 자동 부여하지 않음.
- **중요 변경 발생**: 일정·장소·책임자·주요 결정의 변경(K04). 지금은 통합 변경 수집이 추가로 필요.

### 홈 기본 노출에서 제외할 정보

- 개인별 참가자/학생 전체 명단·연락처·납부 상세: 필요 시 원래 관리 화면에서 열람.
- 모든 구매 사양·영수증·증빙·재정부의 내부 처리 열: 홈 판단에 과도한 상세이며 일부는 보류 또는 권한 제한.
- 모든 업무·문서·회의록·대화 전문: 요약 대상과 이동 경로만 남김.
- 구성원 수·메시지 수·문서 수 등 단순 숫자만의 큰 카드: 지금 필요한 판단과 연결될 때만 사용.
- 근거 없는 준비율·위험 점수·성과 순위·만족도·추세: 추가 수집과 정의 전에는 제공하지 않음.

## 4. 집계와 권한을 정할 때 지켜야 할 구분

1. **0 / 없음 / 미입력 / 집계 전**은 다르다. 집계가 안 된 영역을 정상으로 보고하지 않는다.
2. **행사 수 / 업무 수 / 요청 수 / 품목 수 / 실행분 수 / 사람 수**를 구분한다. 합계에는 집계 단위를 표시한다.
3. **현 상태와 변경 이력**은 다르다. 현재 상태만으로 ‘어제보다’, ‘며칠째’, ‘방금 변경’을 만들지 않는다.
4. **중요도와 지연 사실**은 다르다. 미지정 또는 지연이 있다는 이유만으로 행사 전체를 위험하다고 단정하지 않는다.
5. **열람 권한 / 홈 우선 노출 / 처리 권한**은 각각 결정한다. 숨긴 상세의 집계만 홈에 내보내는 것도 권한 검토 대상이다.
6. **역할은 겹칠 수 있다.** 회장단·부서장·부원, 재정부 소속, 행사 운영 역할, 회의 역할을 한 축으로 취급하지 않는다.
7. **완료와 기록 발행**은 별개다. 행사는 완료되었지만 아카이브는 미발행일 수 있다.
8. **예산과 현금**, **학생회비 납부 상태와 실제 수입액**, **정원과 모집 목표**를 혼동하지 않는다.
