# VADA Web

VADA 운영 제품의 React SPA다. Figma 기반 `prototypes/wireframe/`은 화면 참고 자료이며 이 앱의 코드 원본이 아니다.

## 개발

리포 루트에서 실행한다.

```bash
just dev-web
just lint-web
just typecheck-web
just test-web
just build-web
```

구현 전 루트 `AGENTS.md`, `docs/engineering/README.md`, 이 디렉터리의 `AGENTS.md`, 대상 전달 작업의 승인 기준선을 읽는다.
