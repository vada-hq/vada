# vada web

`specs/figma`의 명세 번들로 화면을 구현하는 제품 프론트엔드다. Vite + React + TypeScript + Tailwind CSS v4 + lucide-react.

- 구현 해석 규칙: `docs/decisions/implementation-conventions.md`와 `specs/figma/<wireframeKey>/interpretation.md`
- 현재 진행: ONB-01 파일럿 (`docs/pilot-onb01.md`)

```powershell
npm install
npm run dev     # 개발 서버
npm run build   # 타입 검사 + 번들
```
