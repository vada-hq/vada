# VADA 화면별 QA 매트릭스

> 기준일: 2026-07-23 · 대상: 현재 와이어프레임 86개 화면 · 근거: `src/app/App.tsx`의 `SCREENS`, `SPEC_DATA`, `docs/VADA_HANDOFF.md`

## 사용 방법

- 각 행은 독립 실행 가능한 QA 케이스다. `핵심 UI·동작`은 나열한 모든 요소를 각각 한 번씩 검증한다.
- 권한 표기가 있는 화면은 허용 역할과 비허용 역할을 모두 확인한다. 상태 전이 화면은 전·후 목록, 연결 화면, 로컬 상태 반영까지 확인한다.
- 기본 검증 환경은 데스크톱 와이어프레임이며, `첫 사용 · 빈 상태` 샘플도 해당하는 목록·보드·기록 화면에서 함께 확인한다.

## 공통 합격 기준

| 구분 | 합격 기준 |
|---|---|
| 화면 전환 | 버튼·카드·탭이 지정된 화면 또는 패널·모달을 열고, 닫기·뒤로가기는 이전 맥락을 보존한다. |
| 권한 | 허용되지 않은 행동은 비활성화가 아니라 노출하지 않으며, 역할·생성자·진행 권한의 범위를 섞지 않는다. |
| 상태 반영 | 생성·수정·배정·상태 변경 결과는 관련 목록·상세·요약·내 업무·캘린더에 즉시 반영된다. |
| 빈 상태·오류 | 결과 없음, 필수값 누락, 중복·마감·권한 없음 등은 성공으로 처리하지 않고 안내와 복구 경로를 제공한다. |
| 데이터 보존 | 읽기 전용 열람, 모달 닫기, 취소 행동은 기존 기록을 임의로 바꾸지 않는다. |
