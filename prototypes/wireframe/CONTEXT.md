# VADA 도메인 용어

VADA 재정 도메인에서 같은 개념을 같은 이름으로 사용하기 위한 용어집이다. 상태 전이·권한·금액 계산·예외 처리의 상세 규칙은 `docs/VADA_FINANCE_SPEC.md`를 따른다.

## 요청과 승인

**구매 요청**: 한 행사에서 필요한 하나 이상의 구매 품목을 묶어 재정부에 검토를 요청하는 제출 단위. 제출 이후 요청 전체 진행 상태를 갖지 않는다.
_Avoid_: 주문, 구매 건

**구매 품목**: 구매 요청에 포함된 개별 물품·제작물·대여·용역. 검토 상태·승인 범위·예산 예약의 원본 단위이며 주문 이후 결과는 소속 구매 실행분에서 집계한다.
_Avoid_: 구매 실행분

**검토 상태**: 구매 필요성·예산·가격 근거와 요청 정보에 대한 재정부의 구매 품목별 판단 상태.

**승인 범위**: 승인된 구매 목적·유형·필수 조건·수량 또는 이행 범위와 요청 금액으로 정해지는 구매 허용 경계.

**선진행 제안**: 재정부가 승인 품목별 선진행 가능 여부와 보류 사유를 정해 요청자에게 전달한 품목 목록.

**선진행 동의**: 보완 품목의 재검토가 끝나기 전에 제안 목록의 승인 품목을 먼저 구매하도록 요청자가 허용한 결정.

**구매 승인 묶음**: 하나의 구매 요청에서 같은 시점에 구매 진행이 허용된 승인 품목을 함께 보존하는 불변 기록 단위. 생성 시 품목별 초기 구매 실행분을 만든다.
_Avoid_: 주문 묶음

**구매 승인 아카이브**: 현재 유효한 구매 승인 묶음과 요청 취소되지 않은 소속 품목·구매 실행분의 현재 결과를 조회하는 기록 목록. 요청 취소로 자동 제외된 품목과 원래 승인 묶음 관계는 전체 요청 아카이브와 감사 기록에서 조회한다.

**보완 제출본**: 보완 재제출 시점의 품목별 수정 전후 값·첨부자료·처리자와 시각을 보존한 불변 기록.

**품목 반려**: 재정부가 해당 구매 품목을 더 이상 구매하지 않기로 확정한 원본 종결 상태.
_Avoid_: 주문 취소, 최종 반려, 반려 완료

**요청 취소**: 원래 구매 요청의 요청자가 해당 품목의 어떤 구매 실행분도 주문 완료되기 전에 사유를 입력해 품목 요청을 철회한 원본 종결 상태. 품목별로 적용하며 전체 요청 아카이브에 기록을 보존하고 활성 칸반·현재 집계·구매 승인 아카이브 표시에서는 제외한다.
_Avoid_: 반려, 주문 취소, 주문 취소 요청

## 구매 실행과 수령·이행

**구매 실행분**: 승인된 한 구매 품목의 수량·이행 범위 중 주문부터 수령 또는 이행, 취소·재주문과 증빙을 일관되게 관리할 수 있는 최소 진행 단위.
_Avoid_: 구매 품목, 주문 묶음

**주문 취소 요청**: 원래 구매 요청의 요청자가 주문 완료 후 수령·이행 완료 전 구매 실행분의 전부 또는 일부를 취소해 달라고 재정부에 제출하는 후속 요청 기록. 원본 주문 상태나 외부 취소 성립 사실이 아니며 재정부 확인 후 성립·불성립으로 종료한다.
_Avoid_: 주문 취소, 환불 요청

**초기 구매 실행분**: 구매 승인 묶음 생성 시 각 구매 품목의 전체 승인 범위에 대해 하나씩 만들어져 주문 대기에서 시작하는 구매 실행분.

**구매 실행분 분할**: 한 실행분의 수량·이행 범위를 서로 다른 상태로 처리해야 할 때 범위 합계와 원래 관계를 보존하며 여러 실행분으로 나누는 것.

**주문 상태**: 구매 실행분의 구매·발주 여부를 나타내는 원본 상태. 구매 품목에는 같은 상태를 저장하지 않고 소속 실행분의 결과를 집계한다.

**수령·이행 상태**: 구매 실행분의 물품 배송·수령 또는 대여·용역 이행 진행과 완료를 나타내는 원본 상태.

**수령 확인 기록**: 재정부가 특정 구매 실행분의 실제 수령자·수량·시각·이상 여부와 확인 근거를 보존한 기록.

**수령 문제 있음**: 파손·오배송 등으로 정상 인수가 아직 확정되지 않았음을 나타내는 보조 표시. 원본 상태나 처리 단계가 아니다.

**주문 취소 후 도착**: 원본 주문 상태가 주문 취소인 실행분의 물품이 나중에 실제로 도착한 예외 사실. 주문 취소를 되돌리거나 수령 완료를 뜻하지 않는다.

**이행 완료 후 용역 대금 조정**: 용역 이행이 모두 끝난 뒤 품질 문제·합의 등에 따라 이미 지급한 대금을 환불·감액·배상하는 사후 금액 변경. 이행 완료 전 미이행 범위를 종료하는 주문 취소와 구분한다.
_Avoid_: 용역 해지

## 주문 취소·재주문·환불

**주문 취소**: 수령·이행 완료 전에 외부 주문의 취소가 성립한 특정 구매 실행분의 원본 주문 상태. 결제·환불 결과 및 품목 반려와 구분한다.
_Avoid_: 환불 완료, 품목 반려

**재주문 실행분**: 주문 취소된 범위를 다시 구매하기 위해 취소 실행분과 연결해 새로 만든 구매 실행분.

**재주문 보류**: 재주문 실행분은 존재하지만 환불·취소 비용·실제 지출 또는 예산 조건 때문에 실제 주문할 수 없는 동안의 계산된 재정부 처리 단계. 원본 주문 상태가 아니다.

**재주문 판단**: 취소의 재정 처리가 정리된 뒤 새 재주문 실행분을 만들지, 재주문하지 않을지 결정해야 하는 계산된 재정부 처리 단계.

**환불 확인 업무**: 결제 후 주문 취소 또는 물품 반환에서 개별 환불과 근거·추가 환불 가능성을 추적해 최종 자금 반환 결과를 확정하는 공통 후속 업무.

**환불 대기**: 판매자의 환불·응답 또는 추가 입금처럼 외부 결과가 남아 있는 동안의 계산된 재정부 처리 단계.

**환불 확인**: 외부 자료가 갖춰져 재정부의 금액 대조와 최종 환불 결과 확정만 남은 계산된 재정부 처리 단계.

**환불 결과**: 비교 기준 금액·누적 환불액·추가 환불 가능성에서 계산한 전액 환불·일부 환불·환불 없음의 최종 결과. 원본 상태나 칸반 열이 아니다.

**취소 순지출액**: 주문 취소 실행분의 취소 대상 결제액에서 누적 환불액을 뺀 금액.

**반환 대상 결제액**: 물품 반환 수량·범위에 대해 판매자가 반환 대상으로 인정한 원래 결제 금액. 비례 배분으로 자동 산정하지 않는다.

**물품 반환**: 수령 완료된 물품을 판매자 등에게 돌려보내는 구매 후속 절차. 원래 주문·수령 완료와 직접 금액을 되돌리지 않는다.
_Avoid_: 주문 취소

**물품 반환 기록**: 물품 반환의 수량·범위·사유·근거와 반환 대상 결제액을 원래 구매 실행분에 연결해 보존하는 재정부 전용 후속 기록.

## 증빙과 예산

**직접 금액**: 영수증에서 특정 구매 실행분에 명확히 귀속되는 상품·용역의 원래 거래 금액. 공통 할인·배송비·수수료와 물품 반환 환불은 포함하지 않는다.
_Avoid_: 실제 지출

**증빙 조정 내역**: 직접 금액에 포함하거나 품목별로 배분하지 않는 배송비·수수료·할인·환불·반환 비용 등의 개별 금액 기록.

**공통 구매 조정**: 증빙 조정액을 행사 예산에 반영하기 위한 시스템 예산 항목. 일반 구매 품목이 아니다.

**증빙 상태**: 구매 실행분이 증빙 묶음 또는 정정본에서 자료·직접 금액·증빙 조정 내역과 실제 지출을 확인하는 진행 상태.

**일부 증빙 완료**: 한 구매 품목의 증빙 대상 실행분 중 일부만 증빙 완료인 집계 결과. 구매 실행분의 원본 상태가 아니다.

**증빙 묶음**: 같은 행사 안에서 실제 구매처·구매 종류·영수증·결제 관계가 있는 구매 실행분을 다시 묶어 증빙과 실제 지출을 정리하는 단위.

**증빙 아카이브**: 한 행사에서 하나 이상의 완료본이 생성된 증빙 묶음의 현재 유효본·이전 완료본·정정본과 연결 구매 실행분·품목·요청·금액·자료·처리 이력을 조회하는 재정부 기록 관점. 별도 처리 단위나 원본 상태가 아니다.

**증빙 묶음 연결**: 이미 존재하는 구매 실행분을 어느 증빙 묶음에서 정산할지 지정하는 관계. 실행분 생성이나 분할이 아니다.

**증빙 묶음 작성 취소**: 증빙 정리 중인 묶음의 마지막 실행분 연결을 해제해 현재 업무와 금액 계산에서 제거한 감사 사건. 별도 상태나 정식 아카이브 단위가 아니다.

**증빙 정정본**: 완료된 증빙 묶음의 자료·거래 정보·금액을 바로잡거나 완료 후 물품 반환을 반영하기 위해 같은 묶음에 추가하는 불변 버전.

**학교 감사 기준**: 학교의 공식 감사 지침·제출 양식에서 요구하는 정보·자료·확인 조건. VADA가 자체 필수 목록이나 대체·면제 기준을 만들지 않는다.

**증빙 자료**: 구매·사용·결제·수령·이행·취소·환불 사실과 필요성을 입증하는 자료.

**증빙 묶음 공통 자료**: 증빙 묶음 전체 또는 여러 구매 실행분에 공통인 거래·결제 사실을 입증하도록 연결한 증빙 자료.

**구매 실행분 자료**: 특정 구매 실행분의 구매·수령·이행·취소·환불 사실을 입증하도록 연결한 증빙 자료.

**구매 품목 자료**: 한 구매 품목의 여러 실행분에 공통인 구매 목적·필요성·사용 사실을 입증하도록 연결한 증빙 자료.

**예산 예약**: 구매 품목 승인 시 요청 금액을 다른 구매가 사용할 수 없도록 확보한 금액.

**실제 지출**: 구매 실행분 직접 금액 합계에 증빙 조정액을 더해 증빙 완료로 확정한 금액. 정정 중에는 마지막 완료본의 금액이 유효하다.
_Avoid_: 직접 금액, 예상 금액

**정산 완료**: 학교 감사 기준·실제 지출·예산 예약 정리가 모두 끝났음을 계산한 구매 품목의 종결 결과. 원본 상태나 재정부 처리 단계가 아니다.

## 표시와 업무 배치

**원본 상태**: 구매 품목·구매 실행분·증빙 묶음 등 처리 단위의 실제 진행 사실을 나타내는 기준 상태.

**대표 진행 상태**: 원본 상태에서 계산해 일반 사용자에게 필요한 조치·예외 또는 마지막으로 달성된 정상 결과를 보여주는 표시.

**처리 단계**: 원본 상태와 남은 조건에서 계산한 재정부의 다음 미완료 업무. 원본 상태가 아니다.

**칸반 위치**: 특정 보드에서 카드가 놓이는 하나의 열. 원본 상태와 별도로 저장하지 않는다.

**재정부 업무 영역**: 재정부 처리 단계를 `요청 검토`, `구매 준비`, `배송·수령·이행`, `환불`, `증빙`의 다섯 업무 목적으로 나눈 상위 표시 구분. 독립 도메인이나 권한 단위가 아니다.

**영역별 작업 보드**: 한 재정부 업무 영역에 속한 처리 단계만 보여주는 작업 관점.

**품목 현황**: 전 구성원이 구매 품목 또는 분리된 구매 실행분의 대표 진행 상태를 확인하는 행사 재정 관점.
